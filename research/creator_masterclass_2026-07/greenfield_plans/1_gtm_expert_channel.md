## 4. The first 5 deliverables — fully specified

All five are workflows Jeff has actually built and run (source: production memory — lead-cleaning recipe, bulk-send QA, expansion/attack-plan research, owner-assignment pipeline analytics, claims-verification). Each is **re-implemented on the synthetic portal** for the camera (D3). Format: 8-14 min, cold-open ≤15s per `playbook/intros.json` (hook shapes from tactic 2.1), a re-hook every 20-40s during the build (oWkUwno6b0E), ~10 direct-address moments (tactic 2.2: Xf_J7kBzxvo — TEST-grade, cheap), no CTA before minute 2 (tactic 2.6: ZKsldrcO_fU). Every video's end screen names ONE specific video — the converter, V5 (tactic 2.5: Eb8wlFawjTw, TvJhpOxFRsE — end-reachers are the highest-intent segment).

**V1 — CRM cleanup.** Working title: **"I let Claude Code loose on 500 dead CRM leads"**
Real basis: the untouched-Canada-leads cleaning recipe (no-activity filter → exclude existing customers via a roster cross-ref → suppression list → junk-domain rules → human-review queue). On camera: the synthetic portal's 500 leads go in messy; Claude Code writes the classification pass; out comes a clean send-list plus an exclusions ledger, with Jeff narrating the judgment calls (why "customer-flag" fields lie, why a roster cross-ref catches what the flag misses). Payoff shot: before/after counts. Hook (killer-stat shape): "My CRM said these 500 leads were fine. 340 of them were junk — here's the 40-minute build that caught it."

**V2 — Account research.** Working title: **"Claude Code researches a target account in 12 minutes (my full build)"**
Real basis: the expansion-plans / pipeline-attack-plans workflow (account → public research → stakeholder map → opportunity hypotheses → first-touch drafts). On camera: run it against a real *public* company that is not a QP prospect (e.g. a well-known public SaaS co), producing the one-pager: what they sell, trigger events from news/filings, likely buying roles, three angle hypotheses, one draft opener. Hook (before/after shape): "This account brief used to take me 90 minutes. Watch it take 12."

**V3 — Outreach QA.** Working title: **"The AI gate that stops my outreach from lying"**
Real basis: two production guardrails — (a) the claims-verification pass (every product/feature claim in a draft must trace to an official source document; born from a real near-miss Jeff tells as an anonymized story) and (b) bulk-send QA (recipient-verification before send, dedup ledger so nobody gets touched twice, per-send activity logging). On camera: Claude drafts 10 outreach emails from V2's research; the QA gate flags an invented capability claim and a duplicate recipient; Jeff explains why the gate exists ("AI drafts confidently claim features you don't sell — one bad claim costs more than a hundred good emails"). This video is the trust-builder of the five — it demonstrates judgment, which is what the advisory buyer is actually buying.

**V4 — Pipeline analytics.** Working title: **"I asked Claude Code where my pipeline is lying to me"**
Real basis: the deal-hygiene and owner-assignment analytics patterns (stale-stage detection, deals missing amount/close date — the same discipline as the existing `feedback_deal_amount_close_date` rule — assignment-date clustering to find neglected lead cohorts, weighted-forecast roll-up vs. face-value pipeline). On camera: the synthetic portal's deal board goes in; out comes a one-page "pipeline truth report" (stale %, naked deals, forecast gap). Hook (counterfactual shape): "Your pipeline review is a work of fiction. Here's the 30-minute build that audits mine every Monday."

**V5 — THE CONVERTER (the one named deeper asset).** Working title: **"The full AI sales-ops stack: how the 4 builds run my week (and how to build yours)"**
Structure: the four builds chained into one operating week (Monday pipeline truth report → research queue → drafted-and-QA'd outreach → CRM stays clean), the build order a team should follow, the failure modes Jeff hit, and the explicit offer: "If you want this running in your team's stack in 30 days, that's exactly what my build sprint is — booking link below and on screen." Every other video's end screen, pinned comment, and description point HERE by name (tactic 2.5); V5's own end screen points at the booking page. This is the Eb8wlFawjTw / Hormozi money-video shape (tactics 2.5, 7.7) executed with a services offer instead of a course.

Republish note: V5 gets re-recorded ~quarterly as the stack grows; the *name* stays stable so old end screens keep converting.

## 6. Metrics + kill/scale criteria

**Tracked weekly in one Sheet** (`GTM_Channel_Scorecard`, extended from the target-list Sheet; the corpus's revenue-per-view lens — Eb8wlFawjTw — is the governing philosophy: judge conversion, not views):
- Leading: ICP-shaped comments/DMs/connections (count + names), booking-page visits per video (`?utm_content=v<n>` attribution — tactic 7.10), V5 views + avg-watch-time (the funnel's true health metric), LinkedIn post impressions on build posts, outbound touches sent / replies.
- Lagging: triage calls held, proposals sent, engagements signed, cash collected.
- Explicitly NOT steering: subs, total views, RPM. Read views only through the young-channel patience doctrine (tactic 7.3 — STRONG: q0G-FzS6uxk, BePppCvXC-k, ROPkHP8jpW0, 9iP588aMFBc): no packaging judgment before day 14 per video, no format write-off before week 4-6, never delete flops.

**Day-30 gate:** D1 clearance resolved in writing; ≥4 videos live; ≥10 outbound conversations started; ≥3 triage calls held. If calls = 0 → the offer wording or target list is wrong, not the content; rewrite the CTA + re-segment the list before touching video format (diagnostic-ladder discipline, tactic 5.9: 8KXlxAKOTdE — distinguish distribution failure from packaging failure from offer failure).

**Day-60 gate:** V5 live ≥3 weeks; ≥8 triage calls cumulative; ≥1 proposal sent. If calls happen but no proposals → qualification problem (wrong viewers booking) → tighten the triage-call screening question and the buyer-intent titling. If proposals but no closes → price/scope objection log → adjust scope before price.

**Day-90 decision:**
- **SCALE** if ≥1 engagement signed (realistic case): raise workshop to $5K, open the retainer tier, keep weekly cadence.
- **CONTINUE-LEAN** if pipeline is real but unclosed (≥2 proposals live): hold cadence, 30 more days — service sales cycles of 30-60 days are normal in Jeff's own day-job experience.
- **KILL/PIVOT** if <5 triage calls total across 90 days despite 13 videos + 120 outbound touches: the market is telling him the packaging of the *offer* (not the videos) fails; salvage = keep LinkedIn motion + outbound with the videos as proof assets, stop weekly production, return the hours to plays #2/#5.
- **HARD KILL** at any point clearance is withdrawn or a conflict emerges at QP (day job is the golden goose — no channel is worth the Country Manager role).
