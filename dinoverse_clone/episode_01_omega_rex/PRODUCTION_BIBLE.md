> Workflow is **image-first**: make a photoreal STILL for each shot, then animate it in **Grok Imagine** (6s/720p, native audio incl. dialogue). Owner rejected Veo ("doesn't look real"). **Voiceover is INTRO-ONLY**; all body speech is Grok-native per clip. See `ORCHESTRATION.md`.

## HOW TO READ A SHOT (two prompts per shot)
- **(A) IMAGE prompt** (makes the still): `STYLE_KIT + character-locks-present + the shot's on-screen/`P:`** delta`. → GPT-Image / Imagen / Grok. Curate the still — realism is won here.
- **(B) GROK i2v prompt** (animates the still): `camera move + action + the (N) dialogue lines + the 🔊 audio note`. → Grok Imagine, 6s/720p, native audio.
- **(N)** = in-clip dialogue → goes in prompt (B) as `<Character> says: "..."`.
- **(VO)** = narrator → **intro only** is a separate track; any `(VO)` tags in the BODY are actually Grok-native — fold those lines into prompt (B).
