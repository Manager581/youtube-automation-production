## 🚀 Complete Workflow

### Prerequisites (One-Time Setup):

```bash
# 1. Install dependencies (if not done)
pip install -r requirements.txt

# 2. Download SFX library (15 minutes, one-time)
python src/production/sfx_library_setup.py guide
# Follow guide to download 20+ free sound effects from Mixkit

# 3. Add background music (optional)
# Download 1-2 tracks from YouTube Audio Library
# Save to: assets/music/
```

### Per-Video Workflow:

#### Step 1: Generate Script (Manual - ChatGPT/Claude)

```bash
# Generate topic ideas
python src/content/topic_generator.py generate 20

# Generate script prompt
python src/content/script_generator.py generate "Your Video Title"

# Copy prompt → paste in ChatGPT/Claude → save response to:
# scripts/drafts/your_topic.md
```

#### Step 2: Generate Veo Clips (Manual - 2-3 hours batch processing)

```bash
# Generate Veo shot list
python src/production/veo_generator.py generate scripts/drafts/your_topic.md

# This creates: prompts/veo_shots/your_topic_shotlist.txt

# Then:
# 1. Open Google AI Studio → Veo 3
# 2. Generate each clip from the shot list
# 3. Download to: assets/veo_clips/your_topic/veo_clip_001.mp4, 002.mp4, etc.
```

**Tip:** Generate Veo clips in batches overnight for multiple videos.

#### Step 3: Record Voiceover (Manual - 20-30 min)

Record your voiceover and save to:
```
assets/voiceovers/your_topic.mp3
```

#### Step 4: Run WATOP Pipeline (Automated - 10-20 min)

```bash
# This does EVERYTHING automatically:
python src/watop_pipeline.py scripts/drafts/your_topic.md assets/voiceovers/your_topic.mp3
```

**What it does:**
1. ✅ Downloads NASA footage automatically
2. ✅ Generates effects timeline (zoom, text, SFX timings)
3. ✅ Creates complete CapCut project with all effects
4. ✅ Generates thumbnail prompts
5. ✅ Generates YouTube metadata

**Output:**
- `output/capcut_projects/your_topic/` - Complete CapCut project
- `prompts/effects/your_topic_effects_timeline.json` - Effect timings
- `prompts/thumbnails/` - Thumbnail prompts for Imagen
- `output/metadata/` - YouTube metadata

#### Step 5: CapCut Final Edit (Manual - 3-5 min)

**Time breakdown:**
- Import project: 1 min
- Generate auto-captions: 2-3 min (automatic)
- Review: 30 sec
- Start export: 30 sec
- **Total: 3-5 minutes**

**Steps:**

1. **Open CapCut Desktop**

2. **Import Project:**
   - Click `File` → `Import` → `Import Draft`
   - Browse to: `output/capcut_projects/your_topic/draft_content.json`
   - Click Open
   - Wait 30 seconds for project to load

3. **Verify Timeline:**
   - All clips should be sequenced
   - Zoom effects visible on clips (scale keyframes)
   - Audio tracks: voiceover, music, SFX
   - Text overlays visible

4. **Generate Auto-Captions:**
   - Click `Text` tab (left sidebar)
   - Click `Auto Captions`
   - Language: English
   - Click `Generate`
   - Wait 2-3 minutes
   - Captions appear automatically

5. **Quick Review (30 seconds):**
   - Scrub through timeline
   - Check captions look good
   - Verify zoom effects are working
   - Listen to audio balance

6. **Export:**
   - Click `Export` (top right)
   - Settings:
     - Resolution: 1920x1080 (1080p)
     - Frame rate: 60 fps
     - Codec: H.264
     - Bitrate: High
   - Click `Export`
   - Save to: `output/videos/`
   - Export starts (20-40 min in background)

**While exporting, move to Step 6...**

#### Step 6: Generate Thumbnail (Manual - 5 min, during export)

```bash
# Thumbnail prompts already generated by pipeline
# Open: prompts/thumbnails/thumbnail_your_topic_*.txt
```

**Using Imagen 3 (your Gemini access):**

1. Go to https://gemini.google.com
2. Copy one of the thumbnail prompts
3. Paste and ask: "Generate an image with this prompt"
4. Download generated image
5. Open in Canva (or Photoshop):
   - Upload the Imagen image
   - Add bold text overlay (white with black outline)
   - Text: Your video title (first 40 chars)
   - Resize to 1280x720
6. Download and save to: `output/thumbnails/your_topic.jpg`

#### Step 7: Upload to YouTube (Manual - 5 min)

```bash
# Metadata already generated by pipeline
# Open: output/metadata/metadata_your_topic_*.txt
```

1. Go to YouTube Studio → Upload
2. Select video from `output/videos/`
3. While uploading:
   - **Title:** Copy from metadata file
   - **Description:** Copy from metadata file (includes chapters)
   - **Thumbnail:** Upload from `output/thumbnails/`
   - **Tags:** Copy from metadata file
   - **Category:** Science & Technology
4. Publish or Schedule

## 🔧 Troubleshooting

### "CapCut won't import the draft file"

**Possible causes:**
1. Draft file corrupted
2. CapCut version mismatch
3. File paths broken

**Solutions:**
1. Make sure you're using **CapCut Desktop** (not mobile)
2. Try updating CapCut to latest version
3. Check that video/audio files still exist in `assets/` folders
4. Re-run pipeline to regenerate project

### "Auto-captions not generating"

**Solutions:**
1. Make sure CapCut Desktop is updated
2. Check internet connection (auto-captions require online)
3. Try manual captions: `Text` → `Add Text` → type manually

### "Zoom effects not visible"

**Solutions:**
1. Check timeline zoom level (zoom in to see keyframes)
2. Look for scale keyframes on clips (diamond icons)
3. Effects may be subtle (10-30% zoom) - preview video to verify

### "SFX too loud / too quiet"

**Solutions:**
1. In CapCut, select SFX track
2. Adjust volume: 30-50% typically works
3. Or disable SFX track temporarily

### "Export taking forever"

**Normal on M1:**
- 20-min video = 20-40 min export at 1080p 60fps
- Run overnight if needed
- Or export at 30fps for faster processing

### "Missing Veo clips"

**Error:** "No Veo clips found"

**Solution:**
1. Generate Veo clips first (see Step 2)
2. Save to correct folder: `assets/veo_clips/[script_name]/`
3. Name files: `veo_clip_001.mp4`, `002.mp4`, etc.
